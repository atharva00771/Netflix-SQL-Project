## 🌟 Project Overview

This project analyzes the **Netflix Titles Dataset** using **MySQL** to discover meaningful patterns, trends, and business insights from Netflix movies and TV shows.

The project focuses on practical **SQL for Data Analytics**, including filtering, aggregation, grouping, NULL handling, subqueries, and advanced **Window Functions**.
